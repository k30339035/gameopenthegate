# Door Challenge - 3D Game

문을 선택하여 레벨을 진행하는 3D 게임입니다. 캐릭터가 문으로 이동하고 문을 열어 다음 레벨로 진행합니다.

## 게임 규칙

- **레벨 1**: 10개의 문으로 시작
- **레벨 2**: 9개의 문
- **레벨 3**: 8개의 문
- **...계속 진행...**
- **레벨 9**: 2개의 문 (마지막 레벨, 통과하면 승리!)

각 레벨에서 잘못된 문(X 표시)을 선택하면 게임 오버입니다.

## 난이도 시스템

- **Easy**: 각 레벨에 2개의 X 문
- **Medium**: 각 레벨에 3개의 X 문
- **Hard**: 각 레벨에 4개의 X 문

## FBX 캐릭터 사용 방법

게임에 FBX 캐릭터 모델을 추가할 수 있습니다:

1. FBX 파일을 `character.fbx`로 이름을 변경합니다.
2. 게임 폴더(index.html과 같은 폴더)에 `character.fbx` 파일을 복사합니다.
3. 게임을 실행하면 자동으로 캐릭터가 로드됩니다.

### FBX 캐릭터 요구사항

- **애니메이션**: 다음 애니메이션이 포함되어 있으면 자동으로 사용됩니다:
  - `Idle` 또는 `idle`: 대기 애니메이션
  - `Walking`, `walking`, `Walk`, `walk`: 걷기 애니메이션

- **스케일**: 게임 코드에서 자동으로 스케일이 조정됩니다 (기본값: 0.01)
  - 캐릭터 크기를 조절하려면 `game.js` 파일의 99번째 줄을 수정하세요:
    ```javascript
    character.scale.setScalar(0.01); // 값을 변경하여 크기 조절
    ```

### FBX 파일이 없는 경우

FBX 파일이 없어도 게임은 정상적으로 작동합니다. 자동으로 간단한 3D 캐릭터가 생성됩니다.

## 게임 플레이

1. 난이도를 선택합니다 (Easy, Medium, Hard)
2. 문을 클릭하면 캐릭터가 해당 문으로 이동합니다
3. 캐릭터가 문에 도착하면 문이 열립니다
4. 올바른 문을 선택하면 체크 표시와 함께 다음 레벨로 진행합니다
5. 잘못된 문을 선택하면 X 표시와 함께 게임 오버됩니다
6. 9개 레벨을 모두 통과하면 승리합니다!

## 실행 방법

1. `index.html` 파일을 웹 브라우저로 엽니다
2. 또는 로컬 웹 서버를 실행합니다:
   ```bash
   python -m http.server 8000
   ```
   그런 다음 브라우저에서 `http://localhost:8000`을 엽니다

## 파일 구조

- `index.html` - 게임 UI 및 화면 구조
- `style.css` - 스타일링 및 화면 전환 효과
- `game.js` - Three.js 기반 게임 로직
- `character.fbx` - (선택사항) 사용자 정의 캐릭터 모델

## 기술 스택

- **Three.js**: 3D 렌더링
- **FBXLoader**: FBX 모델 로딩
- **HTML5 Canvas**: 렌더링 캔버스
- **CSS3**: UI 스타일링

## 주요 기능

- 3D 환경과 조명 효과
- FBX 캐릭터 로딩 및 애니메이션
- 캐릭터 이동 애니메이션
- 문 열기 애니메이션
- 동적 레벨 생성
- 난이도 시스템
- 승리 및 게임 오버 화면
